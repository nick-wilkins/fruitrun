**Smoothie Scramble: Privacy Policy**

Last updated: [date]

Smoothie Scramble is a game for children made by Nick Wilkins Limited. This page explains what the game does with information. The short version: it collects nothing.

**What we collect**

Nothing. The game has no accounts, no adverts, no analytics and no tracking. We do not collect names, email addresses, locations, photos, contacts, device identifiers or any record of how the game is played.

**What stays on your device**

The game saves progress on the device it is played on: the names typed for each player, stars, fruit, best times, trophies and the sound setting. A player name is only used to tell players apart on that device and to show who is who when playing together. None of this is sent to us or to anyone else. Deleting the game deletes all of it.

**Playing together**

Players in the same room can race each other, each on their own iPad or iPhone. To do this the game asks permission to find devices on the local network. While a game is on, the devices send each other the player's name, the level chosen, where each marble is on the track and the finishing times. This goes directly from device to device. It does not pass through the internet or any server, and it is not stored once the game is closed.

**Purchases**

The game is free to play. One optional purchase unlocks races, cups and playing together. It can only be reached after a question meant for a grown-up. The purchase is handled entirely by Apple. We never see your name, your Apple account or your payment details. Apple tells the game only whether the unlock is owned.

**Children**

The game is made for children and is built so that no personal information is needed or collected from them. The only links out of the game are behind the same grown-up question.

**Other companies**

The game contains no code from advertising or analytics companies and shares no information with any third party.

**Changes**

If this policy changes, the new version will be posted on this page with a new date.
