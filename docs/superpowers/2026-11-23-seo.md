# The website for search engines

Date: 2026-11-23. Branch `main` (Nick: stay on main; the website deploys from it).

## Intent

Nick: audit the six public pages for search (titles, descriptions, structured data), set the Open Graph tags, make
a sitemap, and think about the site as a whole before it is submitted to Google Search Console and Bing.

## What the audit found

Checked: the six pages in `site/`, `server.mjs`, and the live site's answers at smoothiescramble.com.

Already sound: HTTPS with `http` and `www` both sent to the one address; a real 404; one `h1` a page with headings
in order; `lang="en-GB"`; alt text, sizes and lazy loading on pictures; pages compressed; films not fetched until
asked for; every page linked from every footer.

| Found | Matters | Done |
| --- | --- | --- |
| No `sitemap.xml`, and `robots.txt` named none | High | Sitemap of the six pages; `robots.txt` names it |
| No canonical address on any page, and each page answered at three (`/about`, `/about/`, `/about/index.html`) | High | Canonical on every page; the server sends the other two to the one with the slash |
| Titles and descriptions never said "marble run game" or "kids"; About's description ran to 185 characters | High | All six rewritten, titles under 60 and descriptions under 160 |
| No structured data | Medium | JSON-LD on every page (below) |
| Share picture was a 4:3 map with no name on it, so previews cropped it | Medium | `share-card.jpg`, 1200 by 630: the painting with the logo |
| Open Graph had no address, site name, locale or picture size | Medium | Added on every page |
| Favicon was 64 pixels; Google asks for a multiple of 48 | Low | `icon-192.png` linked beside it |
| `/play/` has no words of its own for a search engine to read (the game draws them) | Low | Title, description and structured data carry it. Left as it is |
| No HSTS header | Low | A Cloudflare switch (SSL/TLS, Edge Certificates). Nick's |

Structured data: every page names the maker (Nick Wilkins Limited) and the website (its `name` is what Google shows
as the site name). Home adds the game (`VideoGame` and `MobileApplication`, free, `PreOrder` until release) and the
race film (`VideoObject`). `/play/` adds the race as a free browser game. About is an `AboutPage`. Help is a
`FAQPage` made from the questions on the page. Privacy and terms are plain pages.

Not done, for later: the site has six pages, so it can only be found for its own name and a few phrases. Pages
aimed at what parents search for ("games for kids with no adverts", "offline games for car journeys", "iPad games
with no in-app purchases") are where more visitors would come from. The home page's back seat and no adverts
sections are the start of them.

## Decisions

- Nick: rewrite the titles and descriptions; make the share card.
- Visible words and `h1`s are untouched. Only what is in `<head>` changed.
- `/play/` is built from `web/index.html`; its head was changed there and `npm run build:play` run.
- The redirect is built from the folder found on disk, never from the address asked for, so it cannot be made to
  point at another website.
- No FAQ, breadcrumb or rating markup that the pages do not show.

## On release

  the block says so).
- When a page changes, change its `<lastmod>` in `site/sitemap.xml`.

## Tests

`tests/server.test.mjs`, 5 new, against the real server on a free port. RED before the code: no redirect from
`/about`, none from `index.html`, no sitemap, `robots.txt` named none. GREEN after. The sitemap test also asks for
every page listed and checks that each names the same address as its canonical.

Review (`/code-review medium`) found four small things. Three were fixed: a test that could not fail was replaced by
one that asks for `/about//`, `/about%2F` and `/.%2Fabout/` (RED: 200; GREEN: 301 to `/about/`), the server now
compares the address asked for with the folder's own, and the tests find a free port. The fourth, that a Mac's disk
ignores capitals and so answers `/About`, was left: it is not so on the Linux host.

`npm test`: 1024 pass. `npm run build:play` clean; the built code's names did not change.
